# 藍の単語帳

日本語学習用の単一ページアプリ（N3以下 / N2 / N1 の三段階、全例文にふりがな付き）。

- 語彙 3041 / 文法 164 / 会話 114
- 間隔反復（SRS）、音読（TTS）、小試験、しおり
- 学習記録はブラウザの localStorage に保存（サーバーには送信しない）

## 公開手順（GitHub Pages）

このフォルダの中身をリポジトリのルートに置き、
Settings → Pages → Source を `Deploy from a branch` / `main` / `/ (root)` にする。

## オフライン

`sw.js`（Service Worker）が本体とフォントをキャッシュするため、
一度開けば圏外でも動作する。更新は開くたびに自動で取得する。
