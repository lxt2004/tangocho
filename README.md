# 単語帳（2つのアプリ）

| アプリ | URL | 中身 |
|---|---|---|
| 藍の単語帳（日本語 / JLPT） | `/tangocho/` | 語彙 3041・文法 164・会話 114 |
| 英単語ノート（高校入試 英語） | `/tangocho/en/` | 語彙 690・熟語 160・例文 70 |

どちらも単一ページアプリ。全例文にふりがな、三段階のレベル分け、
間隔反復（SRS）、音声読み上げ、小試験、しおり を備える。

学習記録はブラウザの localStorage に保存され、サーバーには送信されない。
localStorage は**オリジン単位**（パスでは分かれない）ため、
2つのアプリは別々の保存キーを使う：
`ai-no-tangocho/v1`（日本語版）と `eitango-note/v1`（英語版）。
これにより同じ端末で両方を使っても記録が混ざらない。

## オフライン

各ディレクトリの `sw.js`（Service Worker）が本体・フォント・アイコンをキャッシュする。
一度開けば圏外でも動作し、更新はページを開くたびに自動で取得する。

## 公開設定

Settings → Pages → `Deploy from a branch` / `main` / `/ (root)`
